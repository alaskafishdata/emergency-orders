# emergency-orders

> **Public data repo** — ADF&G Emergency Orders (sport + commercial fishing)
> Part of the [alaskafishdata](https://github.com/alaskafishdata) public data network.

## Data Files

| File | Description | Updated |
|------|-------------|---------|
| `data/live-eo.json` | Active sport fishing emergency orders (ADF&G EONR) | Every 2 hours |
| `data/live-commercial-eo.json` | Active commercial EOs | Every 2 hours |

## Source

- **ADF&G Emergency Order Notification & Reporting (EONR) System**  
  https://www.adfg.alaska.gov/sf/EONR/

## Raw API Usage

```
https://raw.githubusercontent.com/alaskafishdata/emergency-orders/main/data/live-eo.json
https://raw.githubusercontent.com/alaskafishdata/emergency-orders/main/data/live-commercial-eo.json
```
